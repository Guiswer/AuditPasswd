# AuditPasswd
AuditPasswd is a Command Line Interface (CLI) tool developed in Python for generating, auditing, and securely storing credentials. The project focuses on three fundamental pillars of information security: Strong Encryption, Data Privacy, and Mathematical Entropy Analysis.

## Features
#### Secure Generation: Uses CSPRNG (Cryptographically Secure Pseudo-Random Number Generator) to ensure password unpredictability.
#### Entropy Calculation: Real-time mathematical assessment of password strength in bits.
#### HIBP Auditing: Integration with the Have I Been Pwned API using K-Anonymity (the password hash never leaves the machine).
#### Encrypted Vault: Binary storage protected by Fernet (AES-256) with robust key derivation.
#### Internationalization (i18n): Full support for Portuguese (PT-BR), English (EN), and Spanish (ES).
#### Dual Interface: Interactive Mode (Wizard) for casual users and Command Prompt for quick operations.

## Security Architecture
#### This project was built following NIST and OWASP recommendations:
1. Encryption and Key Derivation
#### To protect the vault (vault.bin), we do not use the master password directly as a key. We implemented Key Stretching via PBKDF2 (Password-Based Key Derivation Function 2):
#### Algorithm: HMAC-SHA256.
#### Iterations: 600,000 (superior to the recommended standard to mitigate offline brute-force attacks).
#### Salt: 16 random bytes generated by os.urandom for each record, preventing Rainbow Table attacks.
2. Privacy and K-Anonymity
#### When checking if a password has been leaked, SecPass uses the K-Anonymity protocol. Only the first 5 characters of the SHA-1 hash are sent to the API. The final comparison of the full hash is done locally, ensuring the remote server never #### knows which password is being queried.
3. Shannon Entropy
#### Password strength is calculated based on the search space (R) and length (L), using the formula:
#### H = L * log2(R)
#### This provides an objective metric of the theoretical difficulty of cracking the credential in bits of entropy.


## Installation
## Cloning the repository:
```bash
git clone https://github.com/Guiswer/AuditPasswd
```
## Installing dependencies (pip is required):
```bash
pip install -r requirements.txt
```
#
#### After installation, run main.py with python.
#### Example: python main.py

## Manual mode commands:
```bash
-g [Full: --generate]: Generates a new password.
-l [Full: --length]: Sets the length (e.g., 32 characters).
-a [Full: --audit]: Performs a leak audit.
-s [Full: --save]: Saves the password to the vault.
-r [Full: --retrieve]: Retrieves and decrypts passwords from the vault.
```
```bash
[>] Command: -g -a -s -l 24
[>] Full command: --generate --audit --save --length 24
[>] Mixed command: -g --audit --save -l 24
```
